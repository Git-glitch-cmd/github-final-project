# Simple Interest Calculator

A simple Bash script that calculates simple interest based on user input.

## Purpose
This project is part of the IBM "Introduction to Git and GitHub" final project. It demonstrates a basic Bash calculator that computes simple interest from three inputs: principal amount, annual rate of interest, and time period in years.

## Formula
Simple Interest = (Principal x Rate x Time) / 100

## Files in this repository
- `simple-interest.sh` - Bash script for the calculator
- `LICENSE` - Apache 2.0 license
- `CONTRIBUTING.md` - contribution guidelines
- `CODE_OF_CONDUCT.md` - community code of conduct

## Usage
1. Clone the repository:
   git clone https://github.com/Git-glitch-cmd/github-final-project.git
2. Go into the folder:
   cd github-final-project
3. Run the script:
   bash simple-interest.sh
4. Enter the principal, rate of interest per year, and time period in years when prompted.

## Example
Enter the principal:
1000
Enter rate of interest per year:
10
Enter time period in years:
2
The simple interest is:
200
